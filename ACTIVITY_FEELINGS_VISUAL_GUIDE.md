
## User Flow Diagram

```
User taps activity icon
        ↓
  Modal opens
        ↓
┌───────────────────────────────┐
│  1. FEELINGS (always first)   │ ← Quick emoji tap
│     Context-aware emotions    │
│     based on activity type    │
└───────────────────────────────┘
        ↓
┌───────────────────────────────┐
│  2. DURATION (if relevant)    │ ← Only for time-bound activities
│     - Sports: Yes             │
│     - Shopping: No            │
│     - Weather: No             │
└───────────────────────────────┘
        ↓
┌───────────────────────────────┐
│  3. INTENSITY (if relevant)   │ ← Only for effort-based activities
│     - Workout: Yes            │
│     - Reading: No             │
│     - Meditation: Yes (mental)│
└───────────────────────────────┘
        ↓
┌───────────────────────────────┐
│  4. NOTES (always optional)   │ ← Contextual placeholder text
│     Weather: "How did it      │
│              affect you?"     │
│     Other: "Add notes..."     │
└───────────────────────────────┘
        ↓
  User taps Save
        ↓
  Data saved to database
  {
    duration: 30,          // Only if asked
    intensity: 4,          // Only if asked
    postActivityFeeling: 'energized', // Always captured
    notes: 'Great session!' // Optional
  }
```

## Mobile Responsiveness

### Grid Layout:
- **2 columns** on narrow screens (<350px width)
- **3 columns** on standard phones (350-400px)
- Feelings wrap to multiple rows as needed
- Equal button widths with flex distribution

### Touch Targets:
- Minimum 44px height (iOS guidelines)
- 10px gap between buttons (easy tapping)
- Rounded corners (16px) for modern look

## Accessibility

### Screen Reader Support:
```typescript
<TouchableOpacity
  accessibilityLabel={`${feeling.label} feeling`}
  accessibilityHint="Tap to select how you feel after this activity"
  accessibilityRole="button"
  accessibilityState={{ selected: selectedFeeling === feeling.id }}
>
```

### Color Contrast:
- Default text: secondary color (sufficient contrast)
- Selected text: primary color (high contrast)
- Emoji visible in both light and dark modes

## Performance Optimizations

### Memoization:
```typescript
const config = useMemo(
  () => getFeelingsForActivity(categoryId),
  [categoryId]
);
```

### Conditional Rendering:
```typescript
// Only render if needed
{showDuration && <DurationField />}
{showIntensity && <IntensityField />}
```

### Pure Functions:
- All helper functions are pure (no side effects)
- Can be safely called multiple times
- Easy to test and maintain
